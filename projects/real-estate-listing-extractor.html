Real estate listing extractor

Normalize property listings into a structured dataset for local market research and internal analysis.

Runnable demoSelf-initiated demonstrationSynthetic local fixtures

The problem

Property research can involve comparing listing details published in different formats. Inconsistent field names and missing values make manual consolidation slow.

The proposed solution

The fixture extractor maps each property card into a consistent schema, checks required listing identifiers, prices, locations and source URLs, then exports normalized records. This is a demonstration of the workflow against local HTML only.

What it can extract or produce

  • Listing ID
  • Property title
  • Price and currency
  • Location
  • Property type
  • Bedrooms
  • Area (sq ft)
  • Description
  • Listing URL

Implemented features

  • Property-specific field mapping
  • Whitespace normalization
  • Required-field checks
  • Duplicate listing ID removal
  • CSV, JSON, SQLite, and optional XLSX outputs

Technology

Python 3html.parsercsv / jsonsqlite3openpyxl (optional)

Only tools used by the corresponding included script are listed here. Browser automation and external request libraries are not implied.

Sample results

These sample business records are synthetic and generated for demonstration. They are not client data or records collected from a live third-party website.

Representative exported fields include stable identifiers, normalized text, source references, and blank values where optional information is absent. The exact schema for this project is documented in demo_kit/schemas.py.

$ python scraper.py --dataset properties --verbose [INFO] Reading local fixture pages [INFO] Normalizing fields and checking required values [INFO] Removing duplicate record identifiers [INFO] Exporting CSV / JSON / SQLite / optional XLSX

Output formats

  • CSV for spreadsheets and simple data pipelines
  • JSON for programmatic integrations
  • SQLite for local querying and review
  • XLSX when the optional openpyxl package is installed

Data quality

The current demonstration normalizes whitespace, validates required fields, removes duplicate IDs and writes a report of missing optional values. It does not invent absent values. A live engagement would add source-specific checks and agreed acceptance samples.

Business value

A permitted property dataset can support area-level research, listing comparisons, internal lead qualification, and market trend analysis. It should be sourced only where collection and use are authorized.

Project evidence and reproduction

Run the corresponding dataset command in the demo kit, then inspect the generated CSV, JSON, SQLite database, and optional XLSX workbook. The project bundle contains the fixtures and reproduction instructions.

Run `python scraper.py --dataset properties --verbose`. The sample CSV is included in the downloads folder.

Limitations

No live property portal is connected. The example does not infer missing prices, verify availability, geocode addresses, or determine property ownership. All records are synthetic.
