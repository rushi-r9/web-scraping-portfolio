Business directory data collector

Build clean business records from permitted directory sources while keeping source references attached.

Runnable demoSelf-initiated demonstrationSynthetic local fixtures

The problem

Business research data may be spread across category pages and directory listings, with inconsistent formatting and duplicate entries.

The proposed solution

The business schema extracts only fields present in the fixture, keeps the source URL alongside each row, validates key fields, and removes duplicate business IDs. Public contact details are included only as synthetic examples.

What it can extract or produce

  • Business ID
  • Business name
  • Category
  • Website
  • Public phone (if supplied)
  • Location
  • Source URL

Implemented features

  • Category and location normalization
  • Source URL retained for traceability
  • Optional public phone field
  • Duplicate removal and missing-field counts
  • Spreadsheet and machine-readable exports

Technology

Python 3html.parsercsv / jsonsqlite3openpyxl (optional)

Only tools used by the corresponding included script are listed here. Browser automation and external request libraries are not implied.

Sample results

These sample business records are synthetic and generated for demonstration. They are not client data or records collected from a live third-party website.

Representative exported fields include stable identifiers, normalized text, source references, and blank values where optional information is absent. The exact schema for this project is documented in demo_kit/schemas.py.

$ python scraper.py --dataset businesses --verbose [INFO] Reading local fixture pages [INFO] Normalizing fields and checking required values [INFO] Removing duplicate record identifiers [INFO] Exporting CSV / JSON / SQLite / optional XLSX

Output formats

  • CSV for spreadsheets and simple data pipelines
  • JSON for programmatic integrations
  • SQLite for local querying and review
  • XLSX when the optional openpyxl package is installed

Data quality

The current demonstration normalizes whitespace, validates required fields, removes duplicate IDs and writes a report of missing optional values. It does not invent absent values. A live engagement would add source-specific checks and agreed acceptance samples.

Business value

A permitted business dataset may support market mapping, territory planning, supplier research, and account list preparation. Use only information appropriate for the intended business purpose.

Project evidence and reproduction

Run the corresponding dataset command in the demo kit, then inspect the generated CSV, JSON, SQLite database, and optional XLSX workbook. The project bundle contains the fixtures and reproduction instructions.

Run `python scraper.py --dataset businesses --verbose`. The exported file includes a source reference column.

Limitations

No bulk personal-data harvesting, private contact discovery, verification of phone numbers, or live directory connector is provided. All company records are synthetic.
