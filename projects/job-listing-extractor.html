Portfolio case study · 03

Job listing data extractor

Collect published vacancy information into a searchable, deduplicated job dataset.

Runnable demoSelf-initiated demonstrationSynthetic local fixtures

The problem

Recruiting research and job-market analysis can require reviewing many vacancies and copying the same fields into a spreadsheet. Salary information is often absent or inconsistently formatted.

The proposed solution

The job schema separates stable required fields from optional fields such as salary. Missing salary is left blank rather than guessed. IDs are deduplicated across pages and the output is exported for downstream filtering.

What it can extract or produce

  • Job ID
  • Job title
  • Company
  • Location
  • Published salary (if present)
  • Employment type
  • Experience
  • Description
  • Application URL

Implemented features

  • Optional salary handling without fabricated values
  • Company, location and employment type fields
  • Multi-page extraction
  • Stable ID deduplication
  • Quality report showing missing optional values

Technology

Python 3html.parsercsv / jsonsqlite3openpyxl (optional)

Only tools used by the corresponding included script are listed here. Browser automation and external request libraries are not implied.

Sample results

These sample business records are synthetic and generated for demonstration. They are not client data or records collected from a live third-party website.

Representative exported fields include stable identifiers, normalized text, source references, and blank values where optional information is absent. The exact schema for this project is documented in demo_kit/schemas.py.

$ python scraper.py --dataset jobs --verbose [INFO] Reading local fixture pages [INFO] Normalizing fields and checking required values [INFO] Removing duplicate record identifiers [INFO] Exporting CSV / JSON / SQLite / optional XLSX

Output formats

  • CSV for spreadsheets and simple data pipelines
  • JSON for programmatic integrations
  • SQLite for local querying and review
  • XLSX when the optional openpyxl package is installed

Data quality

The current demonstration normalizes whitespace, validates required fields, removes duplicate IDs and writes a report of missing optional values. It does not invent absent values. A live engagement would add source-specific checks and agreed acceptance samples.

Business value

A permitted vacancy dataset can help teams analyze hiring demand, compare advertised role requirements, or prepare internal recruiting research.

Project evidence and reproduction

Run the corresponding dataset command in the demo kit, then inspect the generated CSV, JSON, SQLite database, and optional XLSX workbook. The project bundle contains the fixtures and reproduction instructions.

Limitations

No live job board integration, alerting, ranking, or candidate personal-data collection is included. Listings and companies are synthetic fixtures.
